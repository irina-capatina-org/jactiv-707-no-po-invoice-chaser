## 1. Solution Overview

NoPoInvoiceChaser is a headless weekday API Workflow that queries Coupa for invoices in `draft` or `new` status dated within the past 7 days, excludes credit notes and invoices with a linked PO, and sends one Slack DM to the AP SME when qualifying invoices remain. On a clean day (zero qualifying invoices) the workflow ends silently with no message.

| Project | Product | Role | Entry point |
|---|---|---|---|
| `NoPoInvoiceChaser` | API Workflow | Primary — single end-to-end workflow | `code/jactiv-707-no-po-invoice-chaser/NoPoInvoiceChaser/Workflow.json` |

## 2. As-Built Architecture

```
Orchestrator schedule (weekday 10:00 Europe/Bucharest)
  └─► NoPoInvoiceChaser / Workflow.json
        ├── Javascript_DateWindow      calculate windowStart / windowEnd (today−7d … today)
        ├── HTTP_Request_Coupa         GET /api/invoices via IS connection coupa-uipath-test
        ├── Javascript_FilterAndCount  exclude credit-notes & PO-linked lines; count qualifiers
        ├── If_1 (qualifyingCount > 0)
        │     ├── [Then] Javascript_BuildUrl       build Coupa filtered URL
        │     ├── [Then] Javascript_ComposeMessage compose Slack message body
        │     ├── [Then] HTTP_Request_Slack         POST chat.postMessage via IS connection slack-product-test-app
        │     └── [Then] Javascript_CheckSlack      assert HTTP 2xx
        └── [Else] — empty branch; run ends silently (BR-07)
        (TryCatch wraps all steps; catch logs + rethrows — no retry, no error Slack)
```

Delivered topology matches the SDD exactly. No deviations. Both HTTP Request activities use `call: "UiPath.Http"` with `authentication: connector` routing through the IS proxy — no direct vendor credentials in the workflow file. Connections are bound in `code/jactiv-707-no-po-invoice-chaser/NoPoInvoiceChaser/bindings_v2.json`.

## 4. Exception and Error Handling

| Error ID | Scenario | Detected in | Behaviour | Job state |
|---|---|---|---|---|
| S1 | Coupa query non-2xx or unparseable | `Javascript_FilterAndCount` — `response.statusCode` check | `throw new Error(...)` → caught by `Try_Catch_1` → log + rethrow | Faulted |
| S2 | Slack delivery non-2xx | `Javascript_CheckSlack` — `response.statusCode` check | `throw new Error(...)` → caught by `Try_Catch_1` → log + rethrow | Faulted |
| S3 | IS connection unreachable | Exception from `HTTP_Request_Coupa` or `HTTP_Request_Slack` | Propagates to `Try_Catch_1` → log + rethrow | Faulted |
| S4 | IS credential expiry / auth failure | Exception from HTTP Request activity | Propagates to `Try_Catch_1` → log + rethrow | Faulted |
| S5 | Unhandled runtime exception | Any uncaught throw inside `Try_Catch_1` | `Javascript_LogError` logs message; rethrows | Faulted |

No retry policy. No error Slack notification. Single catch boundary at workflow edge (`Try_Catch_1` in `code/jactiv-707-no-po-invoice-chaser/NoPoInvoiceChaser/Workflow.json`). BR-08/BR-09 text is authoritative (OQ-02 default applied).

## 5. Operations Runbook

### Trigger and Schedule

Orchestrator weekday schedule, 10:00 Europe/Bucharest, folder `Fusion2026`. Schedule must be activated post-publish — not activated by the build.

### Manual Execution

```bash
# Static validation (no credentials required)
uip api-workflow validate code/jactiv-707-no-po-invoice-chaser/NoPoInvoiceChaser/Workflow.json --output json

# Live run (requires uip login; WILL send a real Slack DM if qualifying invoices exist)
uip login
uip api-workflow run code/jactiv-707-no-po-invoice-chaser/NoPoInvoiceChaser/Workflow.json --output json
```

### Expected Runtime and Volume

< 30 seconds per run. 1 invocation per weekday. Up to 50 invoices per Coupa page (pagination not implemented — see prerequisites).

### Normal Run Log Indicators

- `Javascript_DateWindow` exits with `windowStart` / `windowEnd` values
- `HTTP_Request_Coupa` returns HTTP 200; `http_request_coupa.statusCode` = 200
- `Javascript_FilterAndCount` logs excluded credit-note IDs via `console.log`
- If count > 0: `Javascript_CheckSlack` exits with `{ sent: true }`; Orchestrator job = Successful
- If count = 0: `If_1#Else` branch runs (empty); Orchestrator job = Successful silently
